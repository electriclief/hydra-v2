Minimum viable set

Four. ProcessWrapper (nothing starts without it), Services (no definitions without it), Scheduler (nothing queues), State (nothing is visible).
Everything else is a convenience over those four: Join makes them findable, Menu makes them usable by a human, Basic_App makes one run locally, ResourceManager arbitrates, Core publishes, Mirror reads, TrainOfThought remembers, SessionDiary records.
