AudioOut

door on port 8163

Turns text into speech and plays it in the room: piper when a voice is installed, Windows System.Speech when it is not, with the answer naming the provider that spoke. Returns the wav as well, and reports piper's own real-time factor instead of a stopwatch.

Concepts

Two providers, one answer

x-tts-provider names who spoke and fellBackFrom names why. A node with nothing installed still talks.

RTF from piper itself

piper prints its real-time factor to stderr; that number is reported rather than a stopwatch over model load.

The file is the interface

SAPI can only write a wav file, never stdout audio, so every provider writes a file and the caller gets that file.

    Wiring
  • needs: piper.exe + voice (comms.piper/comms.voice), ffplay, powershell
  • gives: POST /api/say {text, download}, POST /api/play, GET /api/devices
