## Why — measured, not guessed
  $ cuobjdump --list-elf ggml-cuda.dll
  ELF file 1..N: ggml-cuda.N.sm_70.cubin / sm_75 / sm_80 / sm_86 / sm_89 / sm_90  (repeating blocks)

The fatbin ships sm_70, sm_75, sm_80, sm_86, sm_89, sm_90 only. There is no sm_52 cubin, so the driver has nothing
to run on a Maxwell card. This is exactly the "arch too old" wall — and it is a packaging choice, not a hardware
limit: CUDA 12.4 compiles sm_52 fine.

## The way past it
  audio.cpp source built with -DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=52 (Vulkan off), same box, same model.
