Event_Handler

Module docs — the ONE file. Purpose + the contract (.d.ts) of every file. Generated by npm run docs — edit the sources, not this file.

Purpose

Event_Handler takes events. register(name, handler) puts one on the palette; trigger(name, payload) fires it FIRE-AND-FORGET — the caller never waits — and the outcome lands as its OWN event (`<name>.result` or `<name>.error`), written by the module's quiet wrap. Everything is logged to ONE rolling file at the path the host passes — bounded (~24 h or a byte ceiling; it self-trims) and holding only events that DO something (nothing mousemove-class ever registers).

The SAME path serves a user click and an agent's MCP trigger — one door; the log records who fired (user · agent · process · system). The agent's hand: event_list (the palette), event_trigger (fire), event_log (read the record), event_purge (trim on demand).

Generic — for all projects; no project words inside. Embed it: the ONE FILE another code thread loads is Event_Handler_module.js at the module root — it re-exports the whole surface and adds createModule() / startModule(), and it EXPECTS A LOG PATH: the host passes where events are logged. npm start is different: the module's own local thread.

Run it

npm test          # the gate: build → typecheck → selftest (99 asserts)
npm start         # GUI + API + MCP on http://127.0.0.1:8126
node Event_Handler_module.js   # the embed entry's own check

/**
 * @module logStore
 * @description The event log: ONE rolling JSONL file — append, read, tail, filter, purge.
 *              It keeps itself small: lines older than the retention window are trimmed,
 *              and the file never grows past the byte ceiling (oldest lines go first).
 * @intent Operator ruling (2026-09-16): the log holds only events that DO something and is
 *         not needed beyond ~a day — it is purged periodically and stays bounded. One file,
 *         at the path the host passes; the store owns it and rewrites it atomically.
 */
export type LogSource = 'user' | 'agent' | 'process' | 'system';
/** One line of the log — the record. */
export interface LogLine {
    /** ISO time the event was logged. */
    t: string;
    /** The event's name (a trigger) or `<name>.result` / `<name>.error` (its outcome). */
    name: string;
    /** Who caused it. */
    source: LogSource;
    /** Free-form payload — present only when the caller gave one. */
    payload?: unknown;
    /** For outcome lines: the trigger they belong to. */
    of?: string;
    /** For `<name>.result` lines: what the handler returned. */
    result?: unknown;
    /** For `<name>.error` lines: what the handler threw. */
    error?: string;
}
export interface LogStoreOptions {
    /** The one file this store owns (created on start). */
    file: string;
    /** Keep events younger than this many hours (default 24). */
    retentionHours?: number;
    /** Keep the file under this many BYTES — oldest lines go first (default 8 MiB). */
    maxBytes?: number;
    /** How often the self-trim runs, in ms (default 10 min; 0 disables the timer). */
    purgeIntervalMs?: number;
}
export interface LogReadOptions {
    /** Last N matching lines (default 200; capped at 5000). */
    limit?: number;
    /** Only lines with t >= since (epoch ms). */
    since?: number;
    /** Exact name match. */
    name?: string;
    /** Exact source match. */
    source?: string;
}
export interface LogReadResult {
    lines: LogLine[];
    matched: number;
    fileBytes: number;
}
export interface PurgeResult {
    before: number;
    after: number;
    removed: number;
    bytesBefore: number;
    bytesAfter: number;
}
export interface LogStats {
    file: string;
    bytes: number;
    lines: number;
    retentionHours: number;
    maxBytes: number;
}
export declare class LogStore {
    private file;

    private maxBytes;
    private purgeIntervalMs;
    private timer;
    private closed;
    private appendsSinceSizeCheck;
    constructor(options: LogStoreOptions);
    /** Create the file if missing, trim it once, and arm the periodic self-trim. */
    start(): this;
    /** Append one line. The size check rides every 64th append (throttled, cheap). */
    append(line: LogLine): void;
    /** The file, parsed; or the last N matching lines. */
