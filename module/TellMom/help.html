Tell Mom

One verb for telling the operator something, wherever they are — with a policy so it cannot become a shout, and a receipt so a message that reached nobody is a fact you can see.

No Telegram. The operator does not want it, and there is no adapter for it here. Discord is the phone channel because this rig already has a token — used outbound only: one HTTPS POST per message, no gateway process, nothing that stays connected between messages.

What it is

PieceWhat
POST /api/tell{severity, subject, body, wants, dedupeKey, channels} → delivers, records, returns the receipt.
policydata/policy.json: dedupe window (900s), hourly ceiling (6), quiet hours that alert may cross.
channelspane always (a note turn in Echidna's thread) and discord when a token exists.
receiptsdata/told.jsonl, and node.<ref>.told in State.

The rule

A loop that fails every ten minutes must not ring the phone every ten minutes. So: the same dedupeKey inside the window is muted and says so; the hourly ceiling is measured on what was actually sent; quiet hours mute everything except alert.

Receipts, not silence

Every tell is written whether or not a transport took it — including the muted ones, with the reason (same dedupeKey …, hourly ceiling reached, quiet hours). A channel that is not configured fails with the exact variable it wants; it never pretends to have delivered.

Broker, later

Discord is also the operator's free answer to ISP double NAT between nodes. That inbound side — reading messages, node-to-node brokering — belongs to a broker module that owns the one connection; Tell Mom stays a sender.
