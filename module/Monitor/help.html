Monitor

one slide per topic · dots for every topic · a click that reaches a live agent · door on :8157

Monitor is the page that answers "what is the fleet working on, and what is still unanswered" without asking anyone. It reads the train of thought (module/TrainOfThought/data/thoughts.json) and turns each topic into one slide: state, intent, the questions still open, and the last key messages. Every topic gets a dot. And every slide carries one button that does not link anywhere — it runs the agent on that topic and shows the answer in place.

Three rules

rulewhy
A click reaches a live agent, or says it cannot. The agent door is probed every ten seconds. If nothing answers on :8642 the button is disabled and names the reason, so the page never offers a link that goes nowhere.
The key is read, never stored. The gateway key comes from API_SERVER_KEY in the owner's .env, is read at the moment of a call, and is never logged, cached to disk, or sent to the browser. Absent key is a typed refusal (no_key), not a guess.
An unreadable board is a refusal. If thoughts.json is missing or torn, /api/topics answers 503 with the path. An empty board would look like a quiet fleet; it is not the same thing.

What a slide shows

fieldsource
state, ref, tags, trail countthe topic's own record
unanswerednext[] — the topic's own list of what is still open
key messagesthe last two trail entries, each with its kind

Endpoints

GET /the page
GET /api/topics{ok, counts, topics:[{ref,title,state,intent,questions,messages}]}, 503 when unreadable
GET /api/agent{alive, door, platform, version, key:"present"|"absent", why}, cached 5 s
POST /api/ask{ref, question?} → {ok, answer, ms, usage} · 502 with why when the agent cannot answer
GET /healthdoor, port, thoughts path, agent liveness

Run it

node src/main.js --port 8157 --host 0.0.0.0
  --thoughts C:/AI/hydra-local/module/TrainOfThought/data/thoughts.json
  --gateway  http://127.0.0.1:8642
  --env      C:/Users/User/AppData/Local/hermes/.env

Raised as a ProcessWrapper row named monitor-8157, so it is visible in the app and can be closed like any other door. Depend on TrainOfThought for the data and on the Hermes gateway for the agent.
