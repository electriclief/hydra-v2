# AI Release Monitor — 2026-10-16
Sources: HF `daily_papers` (30 papers, Oct 10–15) · HF trending models (top 500 by `trendingScore`) · targeted queries for `author=amd`, `ROCmFP4`/`ROCmFPX`, `rocm`, plus per-repo file listings.

**Models & tooling**

- **Ternary-Bonsai-2-27B-gguf** (prism-ml) — HF Trending Models — a 27B Qwen3.8-27B derivative shipped as ternary 1-bit (5.9GB) and 2-bit (7.2GB) GGUFs: the first realistic way to run a 27B-class model locally inside your RX 6800's 16GB (2,705 likes / 4.85M downloads).
- **Qwen3.8-27B quantization ecosystem** — unsloth/Qwen3.8-27B-GGUF (5,123 likes / 6.66M dl) and ISTA-DASLab/Qwen3.8-27B-GSQ-RCO-GGUF (2,220 likes / 1.44M dl) — HF Trending Models — the standard GGUF path plus a new mixed-precision (Gaussian-codebook/rank-corrected) scheme for the #1 trending model; the research-lab build is the one worth A/B'ing against Q4_K_M.
- **ROCmFP4 / ROCmFPX** — HF model search (`rocm`, `ROCmFP4`) — an emerging AMD-native GGUF quant format with its own llama.cpp fork, now spreading across VLMs (e.g. MiniCPM-V-4.7-35B-A3B-ROCmFP4-GGUF, Oct 14). Watch it, but be aware the published builds are ~20GB and benchmarked on Strix Halo `gfx1151`, not the RX 6800's `gfx1030`.
- **MiniCPM-V-4.7-1B** (openbmb, official) — HF Trending Models — 1B on-device vision model with a GGUF sibling; small enough to live on the 6GB GTX 1660 for local vision/OCR.
- **LiquidAI/LFM2.5-24B-A2B + unsloth/LFM2.5-24B-A2B-GGUF** (both Oct 13–14) — HF Trending/New — 24B MoE with only 2B active parameters, so GGUF inference is memory-light and fast on mid-range VRAM.
- **Qwen-Image-2.1-Turbo GGUF** (AtomicChat) — HF Trending Models — denoiser quantized to 2.6GB (Q2_K) / 4.2GB (Q4_K) plus an 8-bit text encoder, putting the full image pipeline under 8GB; the parallel community route is abenzerps/Qwen-Image-2.1-Uncensored-Quantized (4,402 likes / 2.4M dl, `comfyui-gguf`).
- **flux-3-image-klein** (black-forest-labs, official; gated) + Abiray/flux-3-image-klein-sd-GGUF — HF New/Trending — official small FLUX.3 release (~300 likes, `-comfy` variant Oct 14), and a stable-diffusion.cpp GGUF re-quant (Oct 15) at Q2_K 2.0GB / Q4_K_M 3.3GB that would fit the 1660 — though that re-quant has only 17 likes and 0 downloads, so treat it as *available*, not *proven*.
- **amd/* official quant series** (llmcompressor W8A8, Quark MXFP4/INT4-AWQ, incl. an Oct 14 W8A8 build) — HF org listing — AMD's own quantization toolchain is the most on-brand path for your card, but the current drops are server-memory sized; tooling signal only, no 16GB-friendly release this cycle.

**Papers (Daily Papers, Oct 10–15)** — nothing this cycle mentions ROCm, Vulkan, GGUF, or explicit ≤8GB VRAM budgets. Two borderline items:

- **EdgeWise** (20 upvotes, 2610.17560) — HF Daily Papers — runs an SLM on the local device and selectively delegates only critical steps to a cloud LLM, i.e. the local-small-model-plus-occasional-offload thesis.
- **Intern-Decision** (19 upvotes, 2610.22131) — HF Daily Papers — 0.8B/2B/4B multimodal decision models with single-consumer-GPU latency numbers; the small two sizes are 6GB-friendly.

Everything else in both feeds (Waypoint-OPD 131 up, MiniMax-H3, LTX-2.5, Drama-3 GGUF at 17–25GB, Nemotron-74B GGUF) cleared the signal bar but not the hardware bar.
