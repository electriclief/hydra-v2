**How to use:**

1. Select `llama-server.exe` (from your llama-cpp-windows build)
2. Select your `.gguf` model file
3. Tweak settings (GPU layers, context size, threads, etc.)
4. Click **▶ Launch**
5. The console mirrors llama-server's output
6. **WebSocket** on port 9999 streams live logs to any external client

The WebSocket protocol sends:
- `LAUNCH_PARAMS` → full launch config header
- `LOG_LINE` → each console line
- `STATUS` → active/waiting + tokens/s

The bundled version uses no external npm packages — it embeds the HTML/CSS/JS inline and uses Node's built-in `child_process` and `ws` (which you can polyfill with a simple `EventEmitter` if needed).
