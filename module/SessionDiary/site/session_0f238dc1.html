- **DavidAU/Qwen3.6-27B-Fable-Fusion-711-Uncensored-Heretic-NM-DAU-NEO-MAX-MTP-GGUF** — [HuggingFace Trending](https://huggingface.co/DavidAU/Qwen3.6-27B-Fable-Fusion-711-Uncensored-Heretic-NM-DAU-NEO-MAX-MTP-GGUF)

- **Why note:** First model I've seen to ship *explicit AMD/VULCAN quantization variants* (IQ4_XS and Q6_K with output tensor in f16 to fix CPU offload issues on AMD hardware). Q4_K quant at ~16GB fits the RX 6800's 16GB VRAM edge-case; the Q6 low-quant at ~20GB can run with partial CPU offload. 700+ ARC-C score — among the strongest 27B-class models for consumer hardware.

- **Nanbeige/Nanbeige4.2-3B** — [HuggingFace Trending](https://huggingface.co/Nanbeige/Nanbeige4.2-3B)
- 4B agentic reasoning model (3B non-embedding) · 26.9k downloads · Apache 2.0
- **Why note:** At ~4B parameters, a Q4 GGUF quant would use ~2.5–3GB — trivially runnable on both the GTX 1660 (4GB) and RX 6800 (16GB) with headroom. Outperforms Qwen3.5-9B and Gemma4-12B on general-agent and reasoning benchmarks. Lightweight enough to serve as a fast local agentic assistant.

- **Audio8/Audio8-TTS-Preview-0.6b** — [HuggingFace Trending](https://huggingface.co/Audio8/Audio8-TTS-Preview-0.6b)
- 0.6B Text-to-Speech model · 2.48k downloads · 152 likes
- **Why note:** At 0.6B parameters, this will run on literally any GPU (even the GTX 1660's 4GB). Tiny footprint for a TTS model — useful if you need local voice generation without cloud APIs.
