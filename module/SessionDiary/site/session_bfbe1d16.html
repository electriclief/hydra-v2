**The new definition:**

- **A server is not a job.** llama-server / sd-server presence means a model is *in memory*, not that the card is busy. The guard now reads the process command line for `--port`, asks `/slots`, and only a request in flight counts.
- **A batch tool is a job.** `llama-cli`, `audiocpp_cli`, `sd` exist only while they work, so presence still means work.
- **CPU-only doesn't preempt a GPU.** A server with no `-ngl` (or `-ngl 0`) never stops the miner — it isn't competing for the card. `sd-server` and `audiocpp_server` are GPU by default.
